# nextjs-expert — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 비밀을 `NEXT_PUBLIC_*`로 선언 | 키가 브라우저 번들에 노출 | `.env*`, Grep `NEXT_PUBLIC_` |
| 2 | 웹 코드에서 마켓 API · LLM · 쿠팡 호출, 마켓 토큰 복호화 | 키 노출 · 레이트 리밋 · 경계 위반 | Grep 마켓 도메인 · `decrypt` · LLM SDK import |
| 3 | 클라이언트 상태만으로 라우트 보호 | 직접 URL 접근 시 우회 | `proxy.ts` · 레이아웃 서버 검사 |
| 4 | `cookies()` · `params`를 await 하지 않음 (Next 16) | 타입 오류 · 런타임 경고 | 사용 위치 |
| 5 | 서버 컴포넌트에서 `window` · `localStorage` | 빌드 · 런타임 오류 | 사용 위치 |
| 6 | 캐싱 기본값을 모르고 갱신 기대 | 주문 · 동기화 목록이 오래된 값 | 페칭 옵션 · 재검증 (버전별 기본값 확인) |
| 7 | 마켓 탭 · 하위 탭을 클라이언트 상태로만 관리 | 새로고침 시 탭 초기화, 공유 링크 불가 | `?market=` · `?tab=` 사용 여부 |
| 8 | 탭 배지 숫자를 화면에서 행을 세어 계산 | 페이지네이션 때 숫자 틀림 | `market_tab_counts` 사용 여부 |
| 9 | 에러 · 로딩 · 빈 상태 누락 | 빈 화면 · 무한 로딩 | 라우트별 `loading`/`error`, 빈 목록 문구 |
| 10 | 응답을 `any`로 소비 | 계약 변경 시 조용히 깨짐 | 타입 · zod 검증 유무 |
| 11 | Route Handler 입력 미검증 · 조직/역할 미확인 | 다른 조직 리스팅 수정, 뷰어 쓰기 | 핸들러 시작부 |
| 12 | 금액을 `Number` 소수 연산, 화면에서 가격 공식 재구현 | 판매가 오차 · 기획과 불일치 | `packages/domain/pricing.ts` 사용 여부 |
| 13 | 요청 바디의 plan · role · price 를 신뢰 | 권한 · 결제 우회 | 서버 판정 값 사용 여부 |
| 14 | `tailwind.config.js` · `@tailwind base` · hex 색 | v3 혼입, 토큰 이탈, 다크 모드 깨짐 | Grep |
| 15 | 반응형 구간 · 글자 크기 하드코딩 | 3구간 기준과 어긋남 | 토큰 사용 여부 |
| 16 | 마법사에서 `alert` · `confirm` 사용, 권한 승인 전 다음 단계 허용 | 흐름 깨짐 · 미연결 계정 생성 | 모달 단계 상태 |
| 17 | 상단 탭 · GNB · 모바일 메뉴 선택 상태를 따로 관리 | 메뉴끼리 선택 불일치 | 라우트 기반 계산 여부 |
