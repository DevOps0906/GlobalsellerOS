# worker-expert — pitfalls (리뷰 1순위 체크리스트)

| # | 함정 | 증상 · 위험 | 확인 방법 |
|---|---|---|---|
| 1 | 응답 유실 후 무조건 재전송 | 같은 상품이 마켓에 두 번 등록 | 전송 전 멱등 키 기록 · 재시도 전 외부 조회 |
| 2 | SKU 를 난수로 생성 | 재전송 시 새 리스팅 생성, 중복 판단 불가 | SKU 생성 함수가 결정적인가 |
| 3 | 401 을 일반 실패로 처리 | 토큰 만료 때마다 잡 실패 · 계정 `error` | 토큰 갱신 1회 후 재시도 경로 |
| 4 | 429 · 5xx 즉시 재시도 루프 | 한도 악화 · 계정 제한 | 지수 백오프 + 지터, 토큰 버킷 |
| 5 | 검증 오류(필수 속성 누락)를 재시도 | 무한 재시도 · 크레딧 낭비 | 오류 분류 `validation` → 재시도 없음 |
| 6 | 마켓 토큰 · 키를 로그 · 오류 메시지 · 잡 결과에 남김 | 계정 탈취 | Grep 로거 호출 · 결과 직렬화 |
| 7 | 서버에서 쿠팡 페이지 대량·자동 크롤링(검색 결과 순회, 간격 1초 미만 조회) | 약관 위반 · IP 차단 | Grep 쿠팡 도메인 fetch 위치 |
| 8 | 파트너스 API 한도 미관리 | 403 반복 · 계정 제한 | 조직별 카운터 · 설정 한도 |
| 9 | 사용자 URL · 이미지 URL 직접 fetch | SSRF(사설 IP, 메타데이터 엔드포인트) | `packages/net` 사용 여부 |
| 10 | 핸들러에 마켓 이름 분기 | 마켓 추가 때마다 핸들러 수정 · 누락 | Grep `market ===` |
| 11 | 원가 0 · 환율 이상값 · 급락을 그대로 반영 | 손해 가격이 마켓에 노출 | 동기화 규칙의 `held` 조건 |
| 12 | 금액을 소수 `number`로 계산, 화면과 다른 공식 | 판매가 오차 · 화면과 불일치 | `pricing.ts` 사용, 정수 연산 |
| 13 | 서비스 롤 쿼리에 `org_id` 조건 누락 | 다른 조직 데이터 처리 | 워커 쿼리 |
| 14 | 하트비트 없는 장시간 잡 | 재시작 후 잡 유실 또는 이중 처리 | 런타임 하트비트 · 재claim 조건 |
| 15 | 같은 주문 중복 수집 · 중복 발송 확인 | 주문 두 행 · 마켓에 송장 두 번 | upsert 키 · 멱등 키 |
| 16 | 외부 응답 원문 전체 저장 | 개인정보 과다 보관 · 용량 | 저장 필드 목록 |
| 17 | 확장프로그램에 넓은 `host_permissions` · 원격 코드 | 스토어 반려 · 보안 위험 | `manifest.json` |
| 18 | 확장 토큰을 장기 · 전 권한으로 발급 | 토큰 유출 시 피해 확대 | 토큰 범위 · 만료 |
| 19 | 크론이 직접 일을 처리 | 재시도 · 환불 · 동시성 규약 우회 | 크론은 잡 등록만 하는가 |
