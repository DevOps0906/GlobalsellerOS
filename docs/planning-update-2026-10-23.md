# GlobalSeller OS 기획 업데이트 — 마켓 탭 · 마켓 추가 · 상품 수집

2026-10-23 · 김대영

GlobalSeller OS 대시보드에 네 가지를 반영했습니다. 운영 메뉴 3개를 마켓별 탭 구조로 바꾸고, 마켓 추가 마법사와 쿠팡 상품 개별 등록·대량 수집 화면을 새로 만들었습니다.

1. 재고·가격 동기화, 주문 통합 관리, 배송·물류 추적을 전체 탭 + 마켓별 탭 공통 구조로 통일
2. 내 여건을 진단해 연결할 마켓을 추천하는 5단계 마켓 추가 마법사
3. 쿠팡 상품 수집을 수집함 / 개별 등록 / 대량 수집 하위 탭으로 재구성
4. 쿠팡 파트너스 API 제약을 반영해 대량 수집 구조를 조정

## 1. 동기화 · 주문 · 배송: 전체 탭 + 마켓별 탭

세 메뉴 모두 페이지 맨 위에 **[전체 · Amazon US · Amazon JP · eBay US · Shopee SG·TH · ＋마켓 추가]** 탭을 두고, 탭을 바꾸면 그 마켓 기준으로 화면 전체가 바뀝니다.

| 탭을 바꾸면 바뀌는 것 | 재고·가격 동기화 | 주문 통합 관리 | 배송·물류 추적 |
| --- | --- | --- | --- |
| KPI 숫자 | 대상 리스팅, 변동, 품절, 실패 | 주문 수, 발주 대기, 금액, 반품률 | 배송 중, 통관, 지연, 평균 배송일 |
| 마켓별 운영 지표 | API 사용률, 환율, 가격 보호 | Amazon ODR·지연 발송률, eBay 판매자 등급, Shopee 늦은 발송률(LSR) | 유효 추적률, 정시 배송률, 핸들링 타임 |
| 목록 | 변동 기록 | 주문 (상태 필터와 같이 적용) | 배송 건, 운송사 |
| 마켓 전용 기능 | Amazon 최저·최고가 보호, eBay 품절 시 리스팅 유지, Shopee 토큰 자동 갱신 | 마켓 판매자센터 바로가기, 발송 확인 일괄 전송 | SLS 송장 출력 |

**설계 포인트:** 전체 탭은 "오늘 처리할 일", 마켓 탭은 "그 마켓의 계정 건전성"을 보여줍니다. 마켓마다 정지 기준이 되는 지표가 달라서 이렇게 나눴습니다.

**구현 메모 (prototype/index.html):** 공통 함수 `setMk(scope, market)` 하나가 세 화면을 처리합니다.

- `data-market` — 행 필터
- `data-only` — 마켓 전용 지표·규칙 표시
- `data-v` — 마켓별 KPI 값(JSON)

## 2. 마켓 추가 마법사 (여건에 맞춘 추천)

여건 진단 답변으로 마켓 8곳의 적합도를 계산해, 지금 바로 연결할 수 있는 마켓부터 추천합니다.

1. **여건 진단** — 7개 질문: 사업자 형태, 통신판매업 신고, 해외 수취 계좌, 해외 결제 카드, 판매 지역, 주력 카테고리, 월 고정비 예산
2. **추천 마켓** — 마켓마다 적합도 점수, 바로 연결 가능 여부, 준비할 것을 표시
3. **계정 연결** — 판매 국가와 계정 별칭을 정하고, 마켓 로그인(OAuth) 또는 API 키로 권한 승인
4. **초기 설정** — 기존 리스팅 읽기 전용 가져오기, 주문 수집 주기, 가격·배송 템플릿, 통화, 재고 버퍼
5. **완료** — 동기화·주문·배송 세 메뉴에 새 마켓 탭이 자동으로 생김

추천 카드에는 월 고정비와 수수료가 붙습니다. 예를 들어 Amazon US는 월 $39.99, Amazon JP는 월 ¥4,900, Etsy는 등록비 건당 $0.20입니다. 정부지원사업과 연계되는 마켓(쇼피코리아 × 중진공)에는 배지를 붙입니다.

마법사는 계정 화면의 [+ 마켓 추가], Lazada [연결하기], 각 운영 메뉴의 [＋마켓 추가] 탭에서 열 수 있습니다.

> 입점 요건·수수료는 마켓 정책에 따라 바뀝니다. 실제 서비스에서는 마켓 데이터를 서버 설정으로 분리해 갱신해야 합니다.

## 3. 쿠팡 상품 수집: 개별 등록 · 대량 수집

상단 버튼을 [＋개별 등록] [⇣대량 수집]으로 바꾸고, 하위 탭을 수집함 / 개별 등록 / 대량 수집으로 나눴습니다.

| 화면 | 단계 | 주요 항목 |
| --- | --- | --- |
| 개별 등록 | URL 입력 → 정보 확인·옵션 선택 → 리스크 검사 → 수집함 저장 | URL·확장프로그램 불러오기, 옵션별 수집, 함께 가져올 항목(이미지·고시정보·리뷰 요약), 리스크 검사(브랜드 판매 제한·이미지 사용 권한·항공 배송 제한), 오른쪽 예상 마진, 저장 후 바로 해외 등록 |
| 대량 수집 | 수집 방식 → 조건 필터 → 수집 실행 → 결과 검토 | 4가지 방식(키워드 · URL 목록 · 확장프로그램 · 정기 수집), API 사용량 표시, 수집 후 적용되는 조건 필터(가격·리뷰·평점·마진·무게·제외어·브랜드), 작업 진행 현황, 제외 사유 통계 |

## 5. 사업적으로 중요한 발견

쿠팡 파트너스 API로는 대량 수집이 어렵습니다.

- **키 발급:** 누적 판매 15만 원 이상으로 최종 승인을 받아야 키가 나옵니다.
- **검색 기능:** 키워드 검색만 되고, 가격 조건을 넣어도 무시된다는 보고가 있습니다.
- **호출 제한:** 한도가 있고, 초과가 반복되면 계정이 제한될 수 있습니다. 한도 수치는 자료마다 달라(공식 문서 분당 50회, 실사용 보고 시간당 10회) 화면에는 보수적으로 10회로 표시했습니다.
- **쿠팡 Wing Open API:** 2023년 7월부터 전체 API에 초당 호출 제한이 적용되고, 초과하면 429 오류가 납니다.

그래서 필터는 수집한 뒤 GlobalSeller 쪽에서 적용하고, 키워드 외에 URL 목록과 확장프로그램 수집을 함께 쓰는 구조로 잡았습니다.

**추천 다음 단계:** MVP에서는 URL 목록 업로드와 확장프로그램 수집을 먼저 만드는 것을 권합니다. API 승인 없이 바로 쓸 수 있어 검증이 가장 빠릅니다.
